# Sketchfab render assets — attribution

Decorated render skins for the reduced-modal demo scenes, fetched
from Sketchfab via `scripts/fetch_sketchfab_models.py`. Each model
is licensed CC-BY 4.0 or CC0 (the fetch script restricts to those
so the assets are redistributable in this repo). CC-BY requires
attribution — the author + source URL below satisfy it. The
committed `.glb` files are geometry-only derivatives (PBR textures
stripped — the flat-shaded batched viewer never uses them).
