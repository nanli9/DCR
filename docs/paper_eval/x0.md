# Stage X0 — Pinned paper configuration + determinism protocol

**Status:** complete. **Config source of truth:** `benchmarks/paper_eval/paper_config.py`
(`PAPER_CONFIG`). **Outputs:** `benchmarks/paper_eval/x0_baseline/out/` (CSVs +
`*.config.json` manifests). **Git baseline:** `0527684`.

## Goal

Every headline result in the paper must come from ONE configuration. Before X0 the
evidence was split across two:

- the material / scene sweeps (`benchmarks/material_sweeps/`) ran at modal
  relaxation **0.7** + the **symplectic** modal step;
- the energy-loop verification (`scripts/probe_native_energy_loop.py`) took a
  `symplectic=` flag but **no relaxation knob**, so it ran at the solver **source
  default** relax (AVBD `_modal_relax = 0.1`, XPBD `modal_relax = 0.25`).

Relaxation is not a cosmetic knob here — it sets how far the modal block converges
each step, which directly changes the ring amplitude and therefore the two-way
ratio. Mixing the two configs produced **contradictory** two-way stories for the
same scene/solver (see below). X0 pins one config, re-runs all three probes under
it, and verifies determinism.

## The pinned configuration (`PAPER_CONFIG`)

| field | value | rationale |
|---|---|---|
| `relax` | **0.7** | robustness-matrix safe operating point (`robustness_matrix.csv`); source defaults 0.1/0.25 suppress the ring |
| `iterations` | **16** | ≥ safe budget (matrix shows XPBD injects at (8,2)) |
| `substeps` | **4** | ≥ safe budget |
| `stepper` | **symplectic** | implicit-midpoint modal step (CPU host, non-cargo) |
| `h` | **1/120 s** | rigid timestep |
| `n_frames_energy` | **220** | energy-loop detail run — longer of the old {220, 140} pair |
| `n_frames_coupling` | **200** | coupling-metrics run — longer of the old {200, 140} pair |
| `settle_frames` / `settle_s` / `ring_window_s` | 8 / 0.30 s / 0.6 s | fixed probe protocol |

This is the empirical safe region for the **un-clamped** solvers. Stage X1 turns
"passive" from this region into a per-step guarantee; until then X0's config is a
characterized safe region, not a proof.

## Result 1 — pinning relax reconciles the energy loop with the sweeps

Energy-loop two-way ratio (object-KE peak two-way / frozen-q̇ one-way), reference
budget 16×4, 220 frames. "OLD" = the committed `docs/native_energy_loop/summary.csv`
at source-default relax; "NEW" = re-run at `PAPER_CONFIG`; "scene-sweep" = the
independent `coupling_metrics` harness, already at relax 0.7.

| scene / solver | OLD two-way (relax 0.1/0.25) | **NEW two-way (relax 0.7)** | scene-sweep (relax 0.7) | agree? |
|---|--:|--:|--:|:--:|
| shelf / avbd  | 0.999  | **6.18**  | 6.18  | ✓ |
| shelf / xpbd  | 28.975 | **14.64** | 14.64 | ✓ |
| ledge / avbd  | 1.225  | **0.59**  | 0.59  | ✓ |
| ledge / xpbd  | 245.808 / 207.578 | **97.61** | 97.61 | ✓ |
| dinner / avbd | 1.117  | **46.58** | 46.58 | ✓ |
| dinner / xpbd | 18.021 | **40.90** | 40.90 | ✓ |

Two things to read off this table:

1. **The old numbers were materially wrong for the paper's config.** The most
   dangerous case is **dinner / AVBD**: at source-default relax it read **1.12×**
   (indistinguishable from no coupling — "dead"), but at `PAPER_CONFIG` it is
   **46.58×** (strongly two-way). shelf/XPBD moved the other way (29 → 15),
   dinner/XPBD 18 → 41. Any claim built on the old mixed table would have been
   self-contradicting against the sweep figures.
2. **At `PAPER_CONFIG` the two independent harnesses agree to the reported digits.**
   The energy-loop probe (`loop_metrics`) and the sweep probe (`coupling_metrics`)
   are different code paths, yet the two-way ratio, passivity, and even the slab
   ring energy match (e.g. shelf/XPBD `Eslab` = 12639.5 mJ in both; ledge/XPBD
   `Eslab` = 84670.3 mJ in both). This is the evidence that all paper numbers now
   share one setup.

Passivity (slab ring peak / impactor KE), NEW energy loop at `PAPER_CONFIG`:
shelf 0.62 (avbd) / 0.44 (xpbd); ledge 0.17 / 0.22; dinner 0.43 / 0.22 — all < 1,
matching the scene sweep. (These hold at the safe budget; the robustness matrix
still shows XPBD > 1 at (8,2). X1 is what makes ≤ 1 a guarantee.)

## Result 2 — determinism gate

shelf/XPBD, two-way ratio, 3 repeats at `PAPER_CONFIG`:

```
trial 0: 14.6408x   trial 1: 14.6408x   trial 2: 14.6408x
mean 14.6408x   spread 0.00%   -> PASS (tol +/- 5%)
```

The three runs are **bit-identical**. The native CPU path has no RNG and is
deterministic; the old "246× vs 208×" wrinkle for ledge/XPBD was **not**
nondeterminism — it was a 220-frame detail pass vs a 170-frame sweep pass of the
same nominal config. Fixing `n_frames` in `PAPER_CONFIG` removes it.

## Result 3 — sweep reproducibility

Re-running `run_scene_sweep.gather` and `run_slab_sweep.gather` (both already at
relax 0.7 symplectic) into `paper_eval/x0_baseline/out/` reproduces the committed
`benchmarks/material_sweeps/out/` numbers:

- `scene_sweep.csv` — **byte-identical** to the committed file (`diff` clean).
- `slab_material_sweep.csv` — identical in every column EXCEPT `f_fem`, which
  differs at the ~13th significant digit (e.g. 21.131194204483318 vs …414). That
  is the iterative full-FEM generalized eigensolver (`scipy.sparse.linalg.eigsh` /
  ARPACK), which is not bit-deterministic run-to-run; it is **not** a config effect,
  and `f_fem` is only ever reported to 0.1 Hz, so no figure is affected. Every
  solver-side quantity (ring freq, two-way, passivity, Eslab, Eimp, deflection) is
  bit-identical — e.g. slab steel two-way avbd 300.8 / xpbd 47.9, oak/XPBD 59.5.

The committed sweep CSVs are therefore already at `PAPER_CONFIG` and are retained
unchanged as the "before" evidence for Stage X1.
