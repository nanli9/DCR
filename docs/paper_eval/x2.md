# Stage X2 — Head-to-head vs original DCR (the C1 follow-up evidence)

**Status:** core comparison complete. **Code:**
`benchmarks/paper_eval/x2_vs_dcr/run_x2.py`. **Out:**
`x2_vs_dcr/out/{x2_response_vs_distance.csv,.png, x2_capability.csv, manifest}`.

## Goal

The first figure a reviewer of a DCR follow-up looks for: the SAME scene under
three arms — rigid-only, paper-DCR, and the native modal constraint — with a
distant-object response-vs-distance curve. An impactor is dropped OFF-CENTRE on a
slab lined with resting "bystander" objects at increasing distance; we measure
each bystander's peak KE (the two-way response) vs its distance from the impact.

## Arms (matched slab operator)

Both modal arms use the SAME slab FEM (`scene_and_gt.build_fem`), so this is a
method-level comparison on matched geometry (paper-vs-SOFA style), not a
solver-controlled ablation.

- **rigid-only** — `DCRWorld(dcr_enabled=False)`: no distant-response machinery.
- **paper-DCR** — `DCRWorld` + `ModalDCRCoupler` (Eq. 10 forced-IIR + post-solve
  Δv = d_max/h kick) + `ConstraintSolver`.
- **native** — the X3 FEM-modal support (q a solver DOF, two-way + X1-passive).

## Result — response-vs-distance (peak distant-object KE, mJ)

| distance [m] | rigid-only | paper-DCR | native |
|--:|--:|--:|--:|
| 0.14 | 2.94 | 13.55 | 9.83 |
| 0.28 | 0.00 | 6.11 | 4.86 |
| 0.42 | 0.00 | 0.93 | 3.20 |
| 0.56 | 0.00 | 0.87 | 2.00 |

- **rigid-only**: no distant response — only the nearest object twitches from
  direct contact; the machinery is genuinely off.
- **paper-DCR**: strong near the impact (13.6 mJ) but a STEEP falloff — the
  response collapses to ~0.9 mJ by 0.42 m (near-field only).
- **native**: slightly softer near the impact (9.8 mJ) but a MUCH gentler falloff
  — it still delivers 2.0 mJ to the farthest object, **2.3× the paper-DCR
  response there**. The native falloff is the slab's low-mode STANDING-WAVE
  spatial profile (X3-C), reached with NO `C·r^-β` fitting; paper-DCR's steeper
  decay is its impulse-localized forced response.

The two curves CROSS: paper-DCR wins near-field, native wins the distant regime —
a genuine, honest difference (not "native is uniformly bigger").

## Honesty / scope notes

- **Method-level, not ablation.** The arms run at their own natural timesteps
  (paper-DCR h=1e-3; native h=1/240) and contact models, so absolute magnitudes
  are not solver-controlled — the comparable feature is the falloff SHAPE and the
  capability table. A solver-controlled ablation (DCR kick inside the native
  solver) is deferred.
- **Native h.** Native is drawn at h=1/240 (≈0.75× the converged amplitude per
  X3-B); at the paper step it would be ~0.56×. The falloff shape is h-independent
  (X3-C), so the distance profile — the point of this figure — stands.
- **Remaining X2 pieces (scoped, not faked):** side-by-side MP4s per scene; the
  repeated-impact energy-drift test (paper-DCR drifts up per X7's double-count,
  native stays bounded by X1) — the mechanism is shown in X7; a dedicated
  N=10-drop drift trace on this scene is the remaining artifact; and the
  dinner-scene response-vs-distance with the off-centre pot (the geometry fix is
  in `dinner_scene_gt.py`; the viser render already shows the qualitative
  two-way kick).

**X2 core complete.** Three arms on one operator: rigid-only shows no distant
response, paper-DCR shows a steep near-field response, and the native constraint
reproduces a gentler ground-truth-validated modal falloff that reaches distant
objects — with an energy guarantee (X1) and shared parameters the paper-DCR arm
lacks.
